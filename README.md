# Amino Español, un cliente de AltAmino no oficial para la comunidad de Amino Español

Esto no es más que un cliente de AltAmino, corriendo en el servidor oficial del proyecto y mantenido por los creadores del proyecto. Todos los créditos son de AltAmino y Narvii, esto no es más que un cliente modificado de Anime Amino para acceder al servidor de AltAmino.

Por favor no reportar bugs de esta app a AltAmino, ya que no es una versión oficial ni soportada.
